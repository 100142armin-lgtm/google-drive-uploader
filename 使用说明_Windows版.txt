【云端极速上传器 v2.0 - Windows 企业免安装版 使用指南】

一、使用步骤（双击即用）：
1. 解压本压缩包至任意文件夹（如桌面）。
2. 双击运行【GDriveUploader.exe】即可打开软件。
3. 选择你的【业务分组】（视频组/效果组/作图组/新人拍摄素材）。
4. 填写【你的名字】以及【接收人/管理员姓名】。
5. 将视频或素材文件夹直接拖入软件窗口，点击【🚀 开始极速上传】。

二、重要说明：
1. 运行前请确保电脑已开启科学上网/VPN 工具（因为 Google 域名国内无法直连）。
2. 软件内置 Google Drive 官方 API v3 Resumable 断点续传协议，若中途网络波动或切换网络会自动重试与恢复。
3. 上传完成后点击【📁 打开云端目录】可一键在浏览器中直达归档目录。
